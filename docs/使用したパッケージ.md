# 使用したパッケージ

| パッケージ                  | 用途             |
| ---------------------- | -------------- |
| `firebase_core`        | Firebase全体の初期化 |
| `firebase_auth`        | 新規登録・ログイン      |
| `cloud_firestore`      | プロフィール、友達、位置情報 |
| `firebase_crashlytics` | クラッシュ情報の収集     |
| `flutter_riverpod`   | 状態管理         |
| `go_router`          | 画面遷移         |
| `flutter_map`        | 地図表示         |
| `latlong2`           | 緯度・経度の型や距離計算 |
| `geolocator`         | 現在位置・位置権限    |
| `shared_preferences` | 端末内の簡単な設定保存  |
| `package_info_plus`  | バージョン情報取得    |
