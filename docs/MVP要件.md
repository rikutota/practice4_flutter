# MVP要件

## アカウント

- メールアドレスとパスワードで登録
- メール確認はMVPでは必須にしない
- パスワードは６文字以上
- ログイン状態を保持
- ログアウト可能
- パスワード再設定を実装
- アカウント削除時は再認証を要求

## プロフィール

- 表示名：必須，１～３０文字
- 自己紹介：任意，最大２００文字
- プロフィール画像：任意
- 公開ID：必須，重複不可
- 公開IDに使える文字：半角英数字とアンダースコア
- Firebase AuthenticationのUIDはユーザーに公開しない
