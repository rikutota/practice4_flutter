# flutterによるモバイルアプリ開発

## 何を作る？

位置情報共有アプリ

## 機能要件

- アカウント機能
  - 新規登録・ログイン・ログアウトができる
- マップ上の自分がいる位置に，自分のアイコンが表示される
- 位置情報共有のオンオフができる

## 画面設計

- アカウント登録画面
- ログイン画面
- ボトムナビゲーションバー
  - 左：プロフィール画面
  - 中央：マップ画面
  - 右： 設定画面

## 画面ごとの要件

### アカウント登録画面

メールアドレスとパスワードで登録可能

### ログイン画面

アカウント作成後，メールアドレスとパスワードの入力でログイン

### プロフィール画面

自分のアイコン画像，名前，プロフィール，自分のIDが表示されている．
「編集」ボタンをタップでそれらを変えられる
友達一覧を見ることが出来る．IDの入力により友達追加をすることができる．

### マップ画面

自分のいる位置周辺のマップが表示されている．スクロールで移動可能．拡大縮小も可能
友達追加をするとその友達のアイコンがマップ上に表示される

### 設定画面

バージョンの確認．ログアウト．アカウントの削除が可能

## 技術選定

フレームワーク：flutter
言語：dart
DB：firestore
認証：fireauthorication
ルーティング：go_router
地図：flutter_map
位置情報取得：geolocator
状態管理：Riverpod
プロフィール画像：Firebase Storage
エラー監視：Firebase Crashlytics
アプリ設定：shared_preferences
環境変数：flutter_dotenv

## アカウント削除の仕様

- 削除対象
  - Firebase Authenticationのユーザー
  - Firestoreのプロフィール
  - 保存中の位置情報
  - 友達関係
  - 送受信した友達申請
  - Firebase Storageのプロフィール画像

## 非機能要件

### パフォーマンス

- マップ表示から友達の位置表示まで3秒以内を目標
- 友達数の上限を決める
- Firestoreの読み書き回数を抑える

### 対応環境

- Androidのみ

### オフライン

- 通信できない場合の表示
- 最後に取得した位置を表示するか
- 更新失敗時の再試行方法

### エラー表示

- ログイン失敗
- 位置情報取得失敗
- ユーザーが見つからない
- 友達申請済み
- 通信エラー
- 権限拒否

## MVP要件

- メールアドレス・パスワード認証
- プロフィール編集
- 公開IDによる友達申請
- アプリ使用中のみ位置情報を更新
- 全承認済み友達への共有オン・オフ
- マップ上に共有中の友達を表示
- 最終更新時刻の表示
- ログアウト
- アカウント削除
- Firestore Security Rules

## MVPに含めないもの
- バックグラウンド共有
- 友達ごとの共有設定
- 移動履歴
- 通知
- 友達とのチャット機能
