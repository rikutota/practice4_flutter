# プロジェクト流れ

## 要件定義

## flutter project作成

- flutter createでプロジェクトを作成する
- git管理を開始

## Firebaseプロジェクト作成

- Firebase CLIをインストール
- FlutterFire CLIをインストール
- Firebaseコンソールでプロジェクトを作成
- firebaseパッケージのインストール
- Firebaseプロジェクトと接続
  - flutterfire configure --platforms=android
- main.dartでfirebaseを初期化
- 基本パッケージのインストール
